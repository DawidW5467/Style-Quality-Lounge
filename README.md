# Style-Quality-Lounge

### Pliki:
1. database.js:
   - W niej jest połączenie do bazy dancyh i kwerendy
2. server.js:
   - W nim jest testowanie kwerend, konfiguracji serwera. Znajdują się w nim endopinty do api (localhost:5555/) - po / można wpisywać np products lub products/1 lub products/category/electonics
3. servieces:
   - Tam są wszelakie sprawdzania i generalnie struktura całego projektu
4. Plik .env:
   - Tam są dane do połączenia do bazy danych w pliku .sql na localhosta zwykłego daj ją
