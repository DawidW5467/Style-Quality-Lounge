# Style-Quality-Lounge

**style-quality-lounge** to nowoczesna aplikacja sklepu internetowego napisana w **Angular** (frontend) oraz **Node.js** (backend). Aplikacja umożliwia kompleksowe zarządzanie procesem zakupowym oraz interakcję użytkownika z bazą produktów.

## Funkcjonalności

- Przeglądanie produktów z bazy danych
- Rejestracja i logowanie użytkownika
- Dodawanie nowych produktów do bazy (dla administratora)
- Składanie zamówień
- Dodawanie produktów do koszyka
- Przeglądanie zawartości koszyka
- Dodawanie adresu dostawy
- Podgląd i edycja profilu użytkownika
- Wylogowanie

Aplikacja została zaprojektowana z myślą o wygodzie użytkownika i wysokiej jakości kodu.
